# Dashboard DSS — Análisis de Ventas Walmart

Sistema de Soporte a Decisiones (sitio estático) para analizar el desempeño de 45 tiendas.

- **Sitio publicado:** https://USUARIO.github.io/dss-ventas-walmart/
- **Fuente de datos:** Walmart Sales Forecast (Kaggle). 6,435 registros, del 5-feb-2010 al 26-oct-2012. Archivo `walmart_sales.csv`, convertido del Excel original sin modificar valores.
- **Tecnologías:** HTML5, CSS3, JavaScript y Chart.js.
- **Integrantes:** _(agrega aquí los nombres)_

## Archivos
- `index.html`: dashboard (diseño, lógica y gráficas).
- `walmart_sales.csv`: datos que lee el dashboard.
- `README.md`: este archivo.

## Contenido
KPI, filtros (tienda, año, tipo de semana, factor externo), gráficas de línea, barras y dispersión, tablas de mejores y peores tiendas y hallazgos calculados automáticamente.

## Publicación
Settings → Pages → rama `main`, carpeta raíz. Los tres archivos deben estar en la raíz del repositorio.

## Uso local
`fetch` requiere servidor: ejecuta `python -m http.server` en la carpeta y abre http://localhost:8000.
